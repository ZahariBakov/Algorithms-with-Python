# Algorithms-with-Python

These are my solutions to a course on algorithms with Python.

Each topic has a `Lab` folder and an `Exercise` folder. Each file is a small script. It reads its input with `input()` and prints the result.

## Topics

- `Recursion - Lab`, `Recursion - Exercise`
- `Searching and Sorting Algorithms - Lab`
- `Graph Theory, Traversal and Topological Sorting - Lab`, `Graph Theory, Traversal and Topological Sorting - Exercise`
- `Graphs Shortest Path and MST - Lab`, `Graphs Shortest Path and MST - Exercise`
- `Dynamic Programming - Lab`, `Dynamic Programming - Exercise`

## Python version

Python 3.10 or newer.

## How to run one file

Run the file with `python`. Then type the input. The script waits for it.

Example: merge sort.

```
python "Searching and Sorting Algorithms - Lab/06_merge_sort.py"
```

Type this line and press Enter:

```
5 3 8 1 2
```

The script prints:

```
1 2 3 5 8
```
